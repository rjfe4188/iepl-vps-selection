## 一、IEPL 到底是什么，与普通香港 VPS 差在哪

IEPL 全称 International Ethernet Private Line，国际以太网专线，本质是一条"二层透传"的私网链路。**广港 IEPL 套餐就是从广州机房入口、香港机房出口，中间不走公网 BGP，而是运营商之间通过专线设备直连**。它的几个常见特征：

- 端内延迟低：广州到香港的物理距离本来就不远，加上二层专线的跳数少，端内值通常稳定在 1~2ms。

- 抖动小：相比走公网的 CN2 GT/GIA、普通 BGP，IEPL 链路不经过大量国际段路由器，受公网波动影响小。

- 双端独立 IP：常见做法是给一台 VPS 同时分配一个入口 IP 和一个出口 IP，入口在国内，出口在香港，业务流量从国内入口连进去之后从香港出口向目标平台或 API 发请求。

- 合规要求高：因为是国内出口产品，主流服务商要求中国身份信息实名，并且采用"省级白名单"，一台机器只允许一个省份的 IP 连入，避免被当成机场或境外回流通道滥用。

把它和直接买一台香港 VPS 的差别放在一起看会更直观：**普通香港 VPS 从境外向国内连回时受 GFW 影响较大，而广港 IEPL 的设计初衷是让你从国内单向连出去访问香港或经香港到全球服务**，并不是反过来用于境外站点建站。

如果你需要的是"在香港放一个公开可以访问的网站"或"对外提供 API 回调"，广港 IEPL 这类产品并不合适，要回到普通香港 CN2/CMI/IX 出口线路。

## 二、广港 IEPL 的真实延迟：端内只是一部分

很多测评里看到"端内 1~2ms"会误以为整条链路就这么快。这个数字指的是**广州机房到香港机房之间的内部延迟**，并不是你真实的端到端体验。完整延迟由三段组成：

1. **本地到广州入口**：取决于你在哪、用的哪家宽带。电信、联通、移动实测到 MKCloud 广州 BGP 入口一般 30~40ms。

2. **端内（广州机房 → 香港机房）**：IEPL 部分，稳定 1~2ms。

3. **香港出口到目标平台**：从香港机房到目标服务器的距离，按目的地不同差异较大。到 GCP 香港节点约 2~3ms，到美西节点 100~150ms，到欧洲 150~200ms。

所以对一个华南地区、家庭宽带是电信或联通的用户来说，从自己电脑 RDP 进入 MKCloud 广港 IEPL VPS、在里面再连谷歌云香港，整体体验感受大约是：本地 30ms+端内 2ms+目标 3ms ≈ 35ms。如果你在北方或运营商是移动，这一段延迟会明显更长一些。

## 四、套餐怎么挑：选 1TB 还是直接上 2TB

这一段给一些编辑判断，而不是商家宣传。

**1TB / 2TB 是大多数个人和小型团队的选择**。1TB 对一个做跨境电商后台 + 偶尔素材上传的用户来说够用，月付 ¥358 这档入门，比直接上 2TB 省 ¥210；但如果你计划在 VPS 上跑持续同步任务（如客户端测试、海外平台回传），流量消耗会很快——2TB 起步更省心。

**2TB → 4TB 是分水岭**。同样 2 核 4G 40GB SSD 配置，4TB 套餐只比 2TB 多 ¥430，对应多一倍流量 + 同样峰值带宽。如果你判断自己每月的真实用量在月中的时候就会逼近 2TB，直接买 4TB 套餐并配合循环优惠码更划算。

**6TB 以上的套餐**主要面向 2 核 4G → 4 核 8G 的硬件升级，对绝大多数个人用户来说性能是过剩的；如果只是带宽不够而 CPU/内存够用，更划算的做法是从 2TB 或 4TB 共享流量套餐改配独享带宽档。

**独享 5M/10M 适合"不在乎流量而在乎速率"的场景**：例如你有一批文件要持续上传到海外平台，按 GB 计费不划算，按月固定速率付费更可控。

## 五、广港 IEPL 适合做什么，不适合做什么

把 MKCloud 知识库里的应用场景翻译一下，广港 IEPL 这类产品的典型用法是：

- 在 VPS 上操作跨境电商后台，例如 eBay、Shopify、亚马逊等需要从中国大陆出口访问的平台。

- 海外平台的 API 调度、客户端测试、海外素材上传。

- 跨境远程办公、海外 OA/CRM 系统访问。

- B2B/B2C 业务的 ERP/CRM 海外段。

明确**不适合**的场景也要知道：

- **不能建站**：广港 IEPL 的出口不接受外部连入。公开站点、支付回调、对外游戏服务端都不适合这种"单向出口"的架构。

- **不是港美平台替代品**：很多人以为"广港路径短，到美国平台也快"。但香港出口不等于美国出口，到了香港之后还要走公网到美西，这一段拉得动 100~150ms，不是 IEPL 段能解决的。如果你的目标是美国方向，沪美 IPLC 这类产品更合适。

- **不适合住宅/原生 IP 需求**：广港 IEPL 的出口 IP 是 IDC 机房 IP（测评显示常见属于 Nearoute 段），不是住宅 IP。依赖平台识别 IP 类型的某些场景，效果没有住宅 IP 方案好。

## 六、购买前必须知道的限制

广港 IEPL 作为合规跨境专线产品，对个人买家有几个硬性要求。这些不是营销话术，是产品本身的设计前提：

1. **实名认证**：下单时需填写国内手机号、身份证号、姓名进行一致性验证。

2. **省级白名单**：开通后需在附加选项中选择一个允许连入的省份，该省份之外的网络无法连接。该省份后续可申请修改。

3. **不支持换地域**：服务开通后不支持更换到其他地域（如沪日、沪美）。如果以后需要切换出口方向，需要重新购买。

4. **退款仅质量原因**：政策上是"仅支持质量问题退款"，需要提供具体的延迟数据或掉线记录等证明。

5. **流量双向计算**：上传下载都计入，对纯下行场景也要预留余量。

6. **支付方式**：支付宝为主，部分活动支持循环优惠码抵扣。

> 这些限制同时意味着 MKCloud 广港 IEPL 不是面向匿名/批量/灰色用途的产品。如果你本身是合规跨境业务或企业远程办公用户，这些前置条件不会造成困扰。

## 八、常见问题

**Q1：广港 IEPL 和沪日 IPLC 怎么选？**

广港走香港出口，端内 1~2ms，适合华南用户访问香港方向或经香港中转；沪日 IPLC 走日本出口，端内 25~28ms，适合日本平台或客户端测试。两者不是替代关系，按目标市场选。

我说一下常见的选择逻辑：做中国香港的电商后台/广告投放平台 → 广港；做日本乐天、亚马逊日本站、雅虎日本 → 沪日；做 Amazon 美国、TikTok 美区等 → 沪美（端内 124~134ms，但出口是真正的美国 IP）。

**Q2：共享流量套餐和独享带宽套餐能切换吗？**

可以在套餐内通过工单升级到更高流量或更高规格，但**降级至更低价格套餐时差价不退**，且不能跨地域（如从广港换到沪日）。

**Q3：1TB 流量套餐能用几天，看我用来做什么。**

如果是日常办公 + 后台操作几百次/天，月用几十 GB；如果是脚本持续抓取公开数据或者海外素材上传，可能几天就耗完。建议刚开始先买 1TB 月付一档看看真实用量。

**Q4：端内 1~2ms 是不是全国都一样？**

不是。端内只覆盖广州机房到香港机房之间这段。从你本地到广州入口的延迟，取决于地理位置和运营商。北方用户或移动宽带用户，本地到入口这一步可能就 60~80ms，整体延迟明显高于华南电信/联通用户。

**Q5：能不能搭建公开网站/支付回调？**

不能。广港 IEPL 是"出口"模式，外部无法连入。建站要选支持入站的产品，例如普通香港 CN2 或者深港 IX。

**Q6：测评里提到的 500GB 起步套餐怎么不见了？**

MKCloud 2026 年商店页在售的共享流量套餐从 1TB 起步。如果你在测评里看到 500GB 那档（¥228/月），那是早期资料中的型号，当前已不在售。看到过时信息的可以以商店页当下显示为准。

**Q7：Telegram 群里的双旦、618 优惠码还能用吗？**

官方明确说过这类活动码（MK-8.8、MK-7.8、MK-NEW 等）的版本仅在活动期内有效，活动结束后就失效。要用循环码建议用 `MK-IEPL-WELCOME`（IEPL 9 折循环），这类不属于活动期码。

## 九、编辑判断与建议

对"广港 IEPL VPS" 这个搜索关键词，相信你更想看到的是"该不该买 / 买哪档"，而不是"什么是 IEPL"。结合 MKCloud 当前套餐我给四条建议：

- **试用阶段买 1TB 月付 + 循环码**：先用 1TB / ¥358 试一个月，看本地到入口、端内、出口三段实际延迟分布，确认是否满足业务需求。配 `MK-IEPL-WELCOME` 9 折循环，可降到约 ¥322/月。

- **业务量稳定后切换到 2TB 或 4TB 并改年付**：流量是双向计费，年付结合活动折扣长期成本更低。

- **持续大流量上传场景选独享 5M/10M**：月付 ¥500~700 档比起共享流量套餐看似贵，但无月度流量限制，对持续任务更划算。

- **目标市场在美区/日区时不要硬买广港**：广港 IEPL 的香港出口不是美国/日本出口，到这些平台要走 HK → 美国/日本的公网段，延迟高且不稳。MKCloud 也有沪日 IPLC、沪美 IPLC，方向一致时再选用对应线路。

广港 IEPL 不是性价比最高的香港 VPS，但它是"在国内出口 + 香港出口"这个特定组合里最稳的一档。买之前先确认业务确实是从大陆出口的客户端连接 / 数据回传场景，再确认你能接受省级白名单和实名，最后按月用量判断该上流量套餐还是独享带宽套餐——这三件事做完之后，选哪一档基本没有悬念。
